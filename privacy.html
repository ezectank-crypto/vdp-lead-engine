隱私權政策 / Privacy Policy

VDP Lead Engine ・ 生效日期 Effective date：2026-10-21

1. 適用範圍

VDP Lead Engine（以下稱「本工具」）是 VDP 的 Tank 個人使用的業務開發工作台，只在 Tank 自己的電腦上執行，不對外開放使用。

2. 存取哪些 Google 資料

  • 寄送郵件（gmail.send）：以 Tank 本人的 Gmail 帳號，寄出 Tank 逐封確認過的商務開發信。
  • 讀取郵件（gmail.readonly）：讀取 Tank 本人的收件匣，用來確認寄出的信是否收到回覆或退信。

本工具只連結 Tank 本人的 Google 帳號，不會要求或存取任何其他人的 Google 帳號。

3. 資料如何使用與保存

  • Google 授權憑證只存放在 Tank 個人電腦的私人資料夾，不上傳到任何伺服器。
  • 從 Gmail 讀到的內容只用於確認回覆與退信狀態，紀錄保存在 Tank 個人電腦上的資料庫。
  • 不出售、不出租、不分享任何資料給第三方，也不將資料用於廣告。

4. Google API 使用聲明

本工具使用與轉移從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規範。

5. 取消授權

可隨時到 Google 帳戶的第三方存取權頁面 移除本工具的存取權。

6. 聯絡方式

對本政策有任何問題，請來信 ezec.tank@gmail.com。

English summary

VDP Lead Engine is a private tool used only by Tank (VDP) on Tank's own computer. It connects only to Tank's own Google account, using gmail.send to send emails that Tank has reviewed and confirmed, and gmail.readonly to check Tank's inbox for replies and bounces. OAuth tokens and any Gmail data stay on Tank's computer. No data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: ezec.tank@gmail.com.
